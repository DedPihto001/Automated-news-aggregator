# Агрегатор новостей рыбной отрасли

MVP-сервис на Python для автоматического сбора публичных новостей о рыбе и
морепродуктах, хранения в SQLite и отправки новых материалов в Telegram.

## Источники

| Источник | Публичная RSS-лента | Описание |
|---|---|---|
| Fishnews | <https://fishnews.ru/rss.xml> | Российский отраслевой портал о рыболовстве и рыбной продукции |
| Fishretail.Ru | <https://fishretail.ru/news/rss> | Новости и события рынка рыбной продукции |

Обе ленты открыты и доступны без учётной записи; их содержимое нормализуется
сборщиками RSS. При ошибке одного источника остальные продолжают обрабатываться,
а ошибка записывается в лог. `collectors/api_collector.py` также содержит
переиспользуемый адаптер публичных JSON API; для этого проекта используются две
указанные RSS-ленты.

## Установка и запуск в Windows PowerShell

Клонируйте репозиторий и перейдите в него:

```powershell
git clone https://github.com/DedPihto001/Automated-news-aggregator.git
cd Automated-news-aggregator
```

1. Создайте и активируйте виртуальное окружение:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

   Если вы уже работаете в подготовленной папке `агрегатор новостей`, перейдите
   в неё перед выполнением команд.

2. Установите зависимости:

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. Создайте Telegram-бота через `@BotFather`, откройте с ним личный чат и
   отправьте `/start`. Получите свой Chat ID доверенным способом (например, из
   ответа собственного бота или локального инструмента) и не публикуйте его
   вместе с токеном.

4. Создайте локальный файл конфигурации:

   ```powershell
   Copy-Item .env.example .env
   notepad .env
   ```

   Заполните `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Остальные параметры
   можно оставить по умолчанию. Файл `.env` исключён из Git.

5. Запустите сервис:

   ```powershell
   python main.py
   ```

   При запуске сборщик сразу опросит источники. Затем APScheduler будет собирать
   новости через интервал `COLLECT_INTERVAL_MINUTES` и отправлять дайджест
   ежедневно в `DIGEST_HOUR:DIGEST_MINUTE` в часовом поясе `TIMEZONE`.
   Не закрывайте окно, пока сервис должен работать.

6. Напишите боту `/digest`, чтобы получить ещё не отправленные материалы, или
   `/start`, чтобы проверить бота. Бот отвечает только в чате, заданном в
   `TELEGRAM_CHAT_ID`. Остановить сервис можно `Ctrl+C`.

## Конфигурация

Настройки читаются из `.env`; пример всех переменных находится в
[.env.example](.env.example):

- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — обязательные настройки бота;
- `DIGEST_HOUR`, `DIGEST_MINUTE`, `TIMEZONE` — расписание ежедневного дайджеста;
- `COLLECT_INTERVAL_MINUTES` — период опроса лент;
- `REQUEST_TIMEOUT_SECONDS` — сетевой таймаут для источников;
- `DATABASE_PATH` — путь к SQLite-файлу;
- `FISHNEWS_RSS_URL`, `FISHRETAIL_RSS_URL` — адреса двух публичных лент.

Секретные данные храните только в локальном `.env`, не в исходном коде и не в
Git. Ключ OpenAI не нужен и не используется.

## SQLite, дедупликация и доставка

Основная таблица `items` имеет поля `id`, `title`, `url`, `source`,
`description`, `created_at`. Уникальный индекс на `url` и `INSERT OR IGNORE`
не дают повторно добавить материал при следующем опросе.

Таблица `delivered_items` хранит состояние доставки отдельно от обязательной
схемы `items`. Материалы помечаются отправленными только после успешной отправки
дайджеста; если Telegram временно недоступен, они остаются в очереди. Материалы
попадают в SQLite только через сборщики, ручных вставок в базу нет.

Ниже — реальные строки SQLite, собранные из публичных лент 6 ноября 2026 года.
Их содержимое будет меняться при последующих запусках:

```text
id | title                                                                  | source     | url
1  | Тверским рыбоводам приготовили компенсации                            | Fishnews   | https://fishnews.ru/news/56681
```

Для просмотра сохранённых записей используйте Python из папки проекта:

```powershell
python -c "import sqlite3; c=sqlite3.connect('data/news.db'); print(*c.execute('SELECT id,title,url,source,description,created_at FROM items ORDER BY id DESC LIMIT 10').fetchall(), sep='\n'); c.close()"
```

## Пример лога

Фрагмент лога реального сбора 6 ноября 2026 года:

```text
2026-11-06 12:43:32 INFO scheduler.jobs: Источник Fishnews: получено 22, добавлено 22 новых материалов
2026-11-06 12:43:38 INFO scheduler.jobs: Источник Fishretail: получено 20, добавлено 20 новых материалов
2026-11-06 12:43:38 INFO scheduler.jobs: Сбор завершён: добавлено 42 новых материалов
```

На момент сбора в SQLite было добавлено 42 материала. Время в `created_at`
хранится SQLite в UTC; время в логах соответствует локальным настройкам системы.

## Для портфолио

**Проект:** автоматический агрегатор новостей российских рыбных сайтов.

**Реализовано:** подключение публичных RSS, нормализация и очистка текста,
SQLite с дедупликацией, graceful degradation при сбое источника, планировщик
APScheduler и Telegram-дайджест по расписанию и команде `/digest`.

**Навыки:** Python backend, внешние источники данных, автоматизация,
планировщик фоновых задач и интеграция с Telegram Bot API.
