Что делает приложение

1
Fishnewsfishnews.ru/rss.xml
2
Fishretailfishretail.ru/news/rss

Ленты нормализуются, очищаются от HTML и сохраняются в SQLite. Уникальный индекс по URL не допускает повторных записей.

APScheduler запускает сбор по интервалу и Telegram-дайджест по расписанию. Команда /digest отправляет новые материалы по запросу.

Токены и chat ID вводятся локально и не включаются в репозиторий.

Автоматический мониторинг открытых RSS-лентFishnews + Fishretail
NEWS AGGREGATOR / PROJECT TOUR 02 — ВВОД И ЗАПУСК

Настройка Telegram и запуск сборщика

Все параметры — через локальный .env. Секреты в кадре скрыты.

Команды в PowerShell

PS> cd "$HOME\Desktop\Course\агрегатор новостей"

PS> .\.venv\Scripts\Activate.ps1

(.venv) PS> python -m pip install -r requirements.txt

(.venv) PS> Copy-Item .env.example .env

(.venv) PS> notepad .env

(.venv) PS> python main.py

При старте выполняется первичный сбор. Затем сервис работает автоматически, пока запущен процесс.

Вводимые настройки .env

TELEGRAM_BOT_TOKEN=[секретный токен бота]
TELEGRAM_CHAT_ID=[ваш Chat ID]

FISHNEWS_RSS_URL=https://fishnews.ru/rss.xml
FISHRETAIL_RSS_URL=https://fishretail.ru/news/rss

COLLECT_INTERVAL_MINUTES=60
DIGEST_HOUR=9
DIGEST_MINUTE=0
TIMEZONE=Europe/Moscow
DATABASE_PATH=data/news.db

Бот отвечает только в заданном чате. Команда /digest запрашивает новые материалы.

Входные данные: RSS-адреса + локальная конфигурацияTelegram credentials не показаны
